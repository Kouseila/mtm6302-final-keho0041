# My Movie Watchlist

## Project Overview
My Movie Watchlist is a web application that helps college students organize movies they want to watch and movies they have already watched.

## Developer
Kouseila Kehoul

## Core Features
- F1: Add a movie
- F2: Change watched status
- F3: Filter movies
- F4: Remove movies

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage
